
# Git Installation & Setup

## 1. Git Installation

Git was installed successfully on my Windows operating system using the official Git website.

Download source: https://git-scm.com/install/windows

I can access Git through Git Bash and the VS Code integrated terminal.

## 2. Git Version Verification

Command executed:

```bash

```

Output:

```text
PASTE YOUR ACTUAL GIT VERSION OUTPUT HERE
```

Explanation:

This command displays the installed Git version and confirms that Git is available in the terminal.

## 3. Global Git Configuration

Commands executed:

```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

Verification command:

```bash
git config --global --list
```

Actual output:

```text
PASTE YOUR ACTUAL CONFIGURATION OUTPUT HERE
```

Explanation:

- `user.name` configures the name associated with my Git commits.
- `user.email` configures the email associated with my Git commits.
- `--global` applies these settings to all repositories for my current user account.

## 4. Basic Terminal Commands

### Command 1: pwd

```bash
pwd
```

Explanation:

Displays the current working directory, helping me identify my current location in the file system.

### Command 2: ls

```bash
ls
```

Explanation:

Displays the files and folders available in the current directory.

### Command 3: cd

```bash
cd Desktop
```

Explanation:

Changes the current working directory to the Desktop folder.

Git was successfully installed and verified on my system.

I configured my global Git username and email, verified the configuration, and practiced basic terminal commands.

I am now ready to use Git for version control and manage project changes.
